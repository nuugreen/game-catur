
# NUGREEN 3D Chess

Game catur 3D berbasis web yang di-host melalui GitHub Pages.

## Fitur
- Papan catur 3D
- Bidak catur dengan model 3D
- Animasi pergerakan bidak
- Pemain melawan komputer
- Pilihan tingkat kesulitan
- Riwayat langkah
- Fitur undo dan permainan baru
- Kontrol kamera 3D

## Teknologi
- HTML, CSS, dan JavaScript
- Three.js 0.147.0
- Three.js OrbitControls
- chess.js 0.10.3

## Menjalankan permainan
1. Buka repository GitHub.
2. Pastikan file index.html berada di folder utama.
3. Buka Settings > Pages.
4. Pada Build and deployment, pilih Deploy from a branch.
5. Pilih branch main dan folder / (root).
6. Simpan dan buka URL GitHub Pages.

## Catatan
Pustaka JavaScript dimuat dari CDN sehingga
permainan memerlukan koneksi internet.
